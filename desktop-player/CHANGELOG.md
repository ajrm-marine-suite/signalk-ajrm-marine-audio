# Changelog

## 0.8.0

- Establish the maintained Audio-repository implementation as the canonical
  AJRM Marine Audio Player source.
- Add Electron Builder targets for Windows x64, universal macOS, Linux x64,
  and Linux ARM64.
- Add automated unsigned preview packaging for GitHub Releases.
- Retain diagnostics, auto-connect, delayed-audio retry, Sound Check caching,
  and Bluetooth keep-alive support from the reviewed player baseline.
